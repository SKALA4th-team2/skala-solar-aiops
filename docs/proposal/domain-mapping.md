# 도메인 매핑표

HAIC 스켈레톤의 개념을 태양광 발전량 예측으로 바꾼 표다. 통합가이드 본문 7번의 양식을 따른다.

"우리 팀" 열은 초안이다. **결정 대기**로 적은 칸은 [`../decisions/`](../decisions/)에 결정 기록이 생기면 그 내용으로 바꾸고 기록을 가리킨다.

| 템플릿 개념 (HAIC) | 우리 팀: 태양광 발전량 예측 | 상태 |
| --- | --- | --- |
| 예측 대상: 다음날 종가 | 다음 날 하루 발전량 (kWh) | 초안 |
| 입력 시퀀스: 최근 20거래일 (close, volume) | 최근 20일 (하루 발전량, 두 번째 값) | 두 번째 값은 결정 대기 |
| 데이터 공급: 대시보드 CSV 업로드 | 대시보드 CSV 업로드 | 열 이름을 그대로 둘지는 결정 대기 |
| 배포 게이트: RMSE ≤ $4.00 | | 결정 대기 |
| 드리프트 신호: 변동성 3배 급변 | | 결정 대기 |
| 재학습: 최근 21거래일 fine-tuning | | 결정 대기 |
| 알림: `aiops.log` 의 `[WARN]` | | 결정 대기 |
| 이해관계자: 투자 분석가, 운영자 | 전력 중개 사업자의 운영 담당자 | 초안 |

## 표가 정해지면 함께 정해지는 것

| 표의 칸 | 정해지는 것 | 고칠 곳 |
| --- | --- | --- |
| 입력 시퀀스 | 요청 스키마, 업로드 파일의 열 | `serving_app/schemas.py`, `datasets/` |
| 배포 게이트 | 게이트 지표와 기준값 | `serving_app/train_and_register.py` |
| 드리프트 신호 | 판정 방법, 임계값, 시뮬레이션 배치 | `serving_app/monitoring/drift_detector.py`, `scripts/simulate_drift.py` |
| 재학습 | 재학습에 쓰는 데이터 범위와 성공 기준 | `serving_app/monitoring/retrain_trigger.py` |

함께 맞출 곳의 전체 목록은 [`../../AGENTS.md`](../../AGENTS.md)의 표에 있다.
