# ② AI 솔루션과 운영 목표

## 통합가이드가 요구하는 것

Pain Point를 해결하는 핵심 기능, 서빙 모델의 역할, 응답 시간·가용성·품질 목표를 제시한다.

## 모델과 입력

발전소별 LSTM이 전날 실적24시간과 대상일 예보24시간을 받아 대상일1시간 발전량24개를 출력한다. 출력 합계는 별도 표시한다. 학습 전용 일사량 기준선에 LSTM 잔차를 더하며, 모델.keras·scaler.pkl·manifest.json을 함께 저장한다. 지역격자 JMA previous_day2 예보를 사용하고 예보 공개시각을 검증한 것으로 주장하지 않는다.

## 목표와 확인 결과

| 항목 | 목표·판정 | 확인 범위 |
| --- | --- | --- |
| 모델 품질 | 전날 같은 시간 기준선 RMSE보다5% 이상 개선,일사량 기준선 대비105% 이하,편향 절댓값15% 이하 | 33개 독립 평가,31개 통과 |

| 응답 시간 | 모델 적재 후 단일 개소 예측 p95≤1초 목표 | 짧은 로컬 반복 요청으로 측정; 장기·동시 부하 SLO 보장은 아님 |
| 가용성 | 운영 목표99%; 장애 시 상태 확인·기존 정상 모델 유지 | 장기 가용성99%를 실측하지 않음; heartbeat·재시작·손상 모델 거절 검증 |

| 배포 안정성 | 게이트 실패 시 기존 버전 유지,통과 모델만 교체·명시적 롤백 | 실제 HTTP와 MLflow v1→v2→v1 |

## 직접 실행한 성능

2024년까지 훈련하고2025년의 완전한 날짜를 평가했다. 하동363일/8712시간에서 LSTM RMSE4.4506kWh,전날 같은 시간 유지7.6077kWh,일사량 기준선5.2036kWh였다. MAE2.1284kWh,편향−3.1697%다. 개소별 결과는 [성능 증빙](evidence/hourly_20261007/README.md)에 있다.

통과 후 최신 자료로 다시 학습한 모델을 운영한다. 화면의 현재 모델 과거 재생 오차와 위 독립 평가 오차는 서로 다르다. 이번 시간별 릴리스의 주 모델은 LSTM이며 과거 일별 XGBoost·Prophet·앙상블 결과를 시간별 성능으로 사용하지 않는다.
