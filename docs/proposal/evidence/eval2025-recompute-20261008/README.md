# 2025년 평가 구간을 다시 계산한 결과

발표자료(기획서)의 성과 수치와 예측 정산금 예상액의 근거다. 2026-10-08 에 [`tools/proposal/eval2025/`](../../../../tools/proposal/eval2025/README.md)의 스크립트로 만들었다.

## 조건

- 대상: 승인된 31곳(후보 33곳 가운데 최초 게이트를 통과한 곳). 평가 구간은 2025년이다.
- 분할, 시드, 모델 구성은 팀의 최초 평가(`tools/hourly/train.py`)와 같다. 그 평가의 발전소별 RMSE 33개와 이 계산의 RMSE 가 일치하는 것을 2026-10-08 에 확인했다.
- 평가 대상 시간은 실적 ÷ 설비 용량이 10% 이상인 시간이다. 예측오차율은 |예측 − 실적| ÷ 설비 용량 × 100 이다.
- 입력의 기상예보는 48시간 선행 자료다. 전날 실적은 제도의 제출 시각(전날 10시, 17시)에 맞추지 않았다. 그 시각에는 전날 실적 전체를 받을 수 없으므로, 실제 참여 조건의 값보다 좋게 나왔을 수 있다.
- 31곳을 하나의 집합전력자원으로 본 것은 가정이다. 설비 용량의 합은 22.9MW 이지만 실제 자원은 계통별로 구성해야 한다.
- 예측 정산금 예상액은 모의 계산이다. 계수 1.0, 2026-07-25 시행 규칙의 단가를 썼다. 전력거래소의 실제 정산과 다르다.

## 파일과 발표자료의 수치

| 파일 | 내용 | 발표자료에서 쓰는 값 |
| --- | --- | --- |
| `metrics.json` | 발전소 33곳의 지표 | 발전소별 예측오차율의 분포 |
| `bundles.json` | 31곳 전체와 지역 묶음의 지표 | 31곳의 평균 예측오차율 9.46%(전날 실적을 그대로 쓴 예측 14.67%), 하나의 자원으로 본 경우 5.30%(같은 비교 10.61%), 6% 이하인 시간의 비율 67.7%(같은 비교 44.4%) |
| `money.json` | 예측 정산금 예상액 | 하나의 자원으로 본 경우 6,410만 원(전날 실적을 그대로 쓴 예측 4,206만 원), 평가 대상 발전량 25.87GWh, 모두 4원을 받을 때의 상한 10,349만 원 |
| `monthly.json` | 달별 지표 | 부록의 달별 표 |
| `cancel.json` | 모았을 때 오차가 지워지는 정도 | 발전소별 오차의 48%가 서로 지워짐, 같은 지역 발전소의 오차 상관 0.72, 다른 지역 0.17 |
| `portfolio.json`, `splits.json` | 공통 시간 수와 설비 용량 합, 분할 일수 | 평가 조건의 설명 |
| `plants.json` | 발전소 33곳의 이름, 지역, 설비 용량과 팀의 최초 평가 요약 | 이 계산은 이름, 지역, 설비 용량만 쓴다. `datasets/hourly/screening.json` 의 값과 같다 |

발전소별 시간별 예측(CSV 33개, 약 16MB)은 넣지 않았다. `run_eval.py` 로 다시 만든다.
