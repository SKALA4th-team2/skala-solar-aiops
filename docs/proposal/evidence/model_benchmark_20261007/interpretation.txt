해석과 권장 방향 (모델/가중치 추가 조정 없음)

1. 수업의 LSTM을 메인으로 유지할 근거가 있다.
   LSTM(시드 42·43·44 평균)의 시험 RMSE는 40.735kWh로 XGBoost 42.160,
   Prophet 42.400보다 낮다. 개별 LSTM 시드는 40.661~41.933kWh였다.
   시드 42만 시험 결과를 보고 우승자로 선택한 것은 아니다.

2. 검증에서 미리 선택한 조합은 LSTM 55% + XGBoost 45%다.
   검증 RMSE 36.255, 최종 시험 RMSE 40.300kWh였다.
   LSTM 평균 대비 약 1.07% 개선이다. MAE는 LSTM 30.732, 이 조합 31.097kWh로
   LSTM이 더 낮았다. 따라서 모든 지표에서 앙상블이 이겼다고 하면 안 된다.

3. 사전에 정한 다른 후보인 LSTM 60% + XGBoost 40%는 시험 RMSE 40.260이었다.
   이 조합은 3모델 비중 탐색과 LSTM>=50% 탐색에서 각각 선택되어 결과표에
   두 이름으로 중복 표시된다. Prophet 비중은 두 경우 모두 0%다.
   시험 결과를 보고 55:45를 60:40으로 다시 조정한 것이 아니다.
   0.04kWh 차이로 새로운 최적 비중이라고 결론 내리지 않는다.

4. 시간 의존성을 일부 반영한 14일 블록 부트스트랩 2,000회에서,
   검증 선택 앙상블 - LSTM의 RMSE 차이 95% 구간은 -1.382~+0.561kWh다.
   이 평가만으로 앙상블이 LSTM보다 안정적으로 우월하다고 단정하기 어렵다.
   같은 조합 - 규칙C의 차이 구간은 -10.311~-1.898kWh다.
   단일 시기·단일 발전소 표본에서 얻은 추정 구간이며 향후 성능 보증이 아니다.

5. 과제 제안: LSTM 서빙/AIOps 경로를 먼저 완성하고 XGBoost·Prophet과
   앙상블은 같은 조건의 비교 실험으로 발표한다. 앙상블을 주 서빙에 넣을지는
   운영 복잡도와 과제의 LSTM 요구를 함께 고려한다. 이번에 앱 모델을 바꾸거나
   MLflow Production에 등록하지 않았다.

검증 범위: 하동 1곳, 2025-02-28~2026-02-27 365일, 매일 전날까지의 실제
발전량과 하루 전 일사량 예보를 쓰는 다음 날 하루 총발전량 예측.
모델 설정과 비중은 앞선 180일에서 결정했고, 시험 전까지의 952개 표본으로
다시 학습했다. 기존 보고서의 시험 264일 성능과 직접 비교할 수 없다.
다른 발전소, 시간별 정산 성능, 서빙 지연, 드리프트·자동 재학습은 미검증이다.
