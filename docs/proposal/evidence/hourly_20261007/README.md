## 기능 검증

- 승인31개 실제저장모델을 로드해 /predict 24개출력·상한·합계와 /ui/energy를 확인했다.
- 길이·중복·시간대·용량·기상·구계약·제외개소 거절, 야간0, 완전/부분 포트폴리오를 확인했다.
- 별도 runtime-verify-*에서 native TensorFlow LSTM 재학습을실행하고 MLflow v2를등록·승격했다. scaler SHA불변과 다른개소버전불변, 롤백, 게이트실패시기존유지를확인했다.
- 자동드리프트→SQLite큐→작업자 step→학습→승격까지실행했다. 모니터 정상/자료부족/설비점검보류도확인했다.
- 손상된모델 cold-load 거절, 캐시에있던정상모델유지, registry alias재조정, 중단작업재큐·2회제한, 단일작업자잠금 통과.
- Node15개회귀검사통과. 프록시의단건예측검사를새24시간계약으로수정했다. 이전일별보관유틸리티검사도통과했다.
- 실제브라우저에서31개목록,하동/남제주전환,24시간예측(하동대상일합계90.46kWh),696시간CSV업로드(normal),AIOps검사(normal),시간별차트를확인했다.

검증 파일: verification.json, recovery.json, summary.json. AIOps 합성 제어자료의 재학습 RMSE는 기능검증용으로만 기록하며 예측성능으로 사용하지 않는다. Docker는 미설치로 실행하지 않았다.
