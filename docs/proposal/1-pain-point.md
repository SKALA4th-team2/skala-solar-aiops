# ① 이해관계자 가치와 문제 정의

## 통합가이드가 요구하는 것

이해관계자의 불편과 중요성, 서비스 장애·응답 지연·모델 품질 저하의 영향을 정의한다. [도메인 매핑](domain-mapping.md)을 기준으로 설계했다.

## 고객과 가치

고객은 가상의 태양광 포트폴리오 운영 담당자이며 팀은 예측·운영 도구의 공급자다. 실제 고객 인터뷰나 계약 실적은 주장하지 않는다.

| 불편 | 영향 | 구현한 대응 | 확인 방법 |
| --- | --- | --- | --- |
| 개소별 자료·예측을 수작업으로 대조 | 시간대별 과대·과소 예측 확인이 늦음 | 31개소 선택,24/72/168시간 실적·예측 차트와 표 | 실제 자료 화면 |
| 모델 입력·단위·시간대 불일치 | 오류 예측과 개소 혼동 | KST 시간 검증,24시간 창,용량 상한,개소별 모델·스케일러 쌍 | 정상 요청·422·제외 개소 검사 |
| 설비 정지와 모델 품질 저하를 혼동 | 정지 구간을 재학습해 정상 모델까지 훼손 | 주간 연속 극저발전은 점검 보류,나머지 저하·오차 증가만 후보 | 정상·보류·드리프트 시나리오 |
| 재학습 이후 모델과 결과 추적이 어려움 | 장애 대응과 되돌리기가 늦음 | SQLite 예측 이력,MLflow 버전,게이트,원자적 교체·롤백 | 동일 입력 v1→v2→v1 응답 |
| 다른 PC에서 시연 환경을 재현하기 어려움 | 제출·인수인계 시 실행 실패 | 모델 전달 ZIP·SHA 검증·깨끗한 상태의 등록·Docker 검증 | 제출 실행 안내와 CI 증빙 |

장애가 발생하면 담당자는 예측을 조회할 수 없고, 지연되면 업무 판단 시점이 늦어진다. 품질 저하는 예측 대비 실적 편차를 키운다. 이 프로젝트는 이를 가시화·추적하는 교육용 서비스이며 손실액·인센티브 증가를 실측한 것은 아니다.

## 이 문서의 표기

현재 구현은 코드로, 실행 결과는 [증빙](evidence/submission_20261008/)으로 확인한다. 목표는 검증 결과와 구분한다. 연구·과거 설계는 [보관 연구](../research/)와 [결정 기록](../decisions/)에서 추적한다.
