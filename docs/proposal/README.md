## 제출 내용

서비스 운영 담당자의 시간별 오차 확인·개소별 품질 관리 불편을 해결한다. 원본 시간별 발전량과 48시간 선행 지역격자 예보로 LSTM을 학습하고, FastAPI·MLflow·SQLite 작업자·프론트를 연결했다. 시간별 자료 확보33개 중 품질 통과31개만 운영한다. 하동 2025 독립 평가 RMSE는4.4506kWh/시간이다.

기상 기반 저발전과 오차 증가를 검사해 재학습 작업을 등록한다. 후보가 최초 품질 한도와 기존 모델을 모두 통과해야 반영하며, 실패하면 기존 모델을 유지한다. 업로드·예측 이력·버전 변경·모니터링·작업 결과를 저장하고 조회한다. 실제 HTTP 시연에서 v1→v2→v1을 확인했다. 합성 드리프트 시연은 기능 검증이며 예측 성능 증빙과 구분한다.
