## 통합가이드가 요구하는 것

추론·헬스체크·업로드·배치 테스트·로그 조회 등 실제 호출되는 엔드포인트 목록(Method, URL, Request/Response 예시, 422 등 에러 응답)을 정리한다. Swagger UI 에서 확인한 내용을 옮기면 된다.

## 스켈레톤의 엔드포인트 (출발점)

아래는 고치기 전 HAIC 스켈레톤의 목록이다. 태양광용으로 스키마를 바꾸면 이 표와 아래 상세를 함께 고친다.

| Method | URL | 역할 |
| --- | --- | --- |
| GET | `/` | 대시보드 |
| POST | `/predict` | 최근 20일 시퀀스를 받아 다음 날 값 하나를 예측 |
| GET | `/health` | 모델 로드 여부, 로딩 방식 |
| POST | `/data/upload` | CSV 업로드 (Date, Close, Volume 필수, 최소 41행) |
| GET | `/data/status` | 최신 업로드 파일의 행 수와 기간 |
| POST | `/predict/batch-test` | 연속된 값(최소 21개)을 받아 20개씩 잘라 예측하고 드리프트를 판정. 41개를 보내면 판정에 필요한 21건이 한 번에 쌓인다 |
| GET | `/logs`, `/logs/{파일명}` | `aiops.log` 목록과 내용 |
