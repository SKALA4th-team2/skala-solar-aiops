- 담당:
- 상태: 작성 전

## 통합가이드가 요구하는 것

모델 버전 전환 전/후 응답, 컨테이너 실행 화면, 드리프트 주입 → 알림 → 재학습 트리거 로그 등 요청 전/후 상태 변화가 드러나는 실제 동작 화면을 캡처·시연한다.

## 남길 것

파일은 [`evidence/`](evidence/)에 둔다. 서버를 내리기 전에 먼저 남긴다.

| # | 화면 | 파일 | 남겼는가 |
| --- | --- | --- | --- |
| 1 | 업로드 완료와 `/data/status` | | |
| 2 | `/predict` 정상 응답과 422 응답 | | |
| 3 | 게이트 통과 로그와 MLflow 에 기록된 지표 | | |
| 4 | 모델 버전 전환 전과 후의 `/predict` 응답 (`model_version`) | | |
| 5 | 컨테이너 실행 화면과 컨테이너의 `/docs` | | |
| 6 | 정상 배치와 드리프트 배치의 판정 결과 | | |
| 7 | `aiops.log` 에 경고, 재학습, 결과가 순서대로 쌓인 화면 | | |
| 8 | 재학습 뒤 `/predict` 가 어느 버전으로 응답하는지 | | |
