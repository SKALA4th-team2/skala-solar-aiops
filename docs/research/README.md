# 조사 보고서

프로젝트를 시작하기 전에 한 사전 조사와 데이터 분석의 결과를 둔다. 기획서와 결정 기록이 근거로 가리키는 곳이다.

## 들어올 문서

| 문서 | 내용 | 상태 |
| --- | --- | --- |
| 통합 보고서 | 사전 조사(발전소, 데이터 정의, 날씨 자료, 제도, 선행 연구, 손익)와 ASOS 분석을 주제별로 대조해 합친 것. 팀이 정할 것과 권고가 들어 있다 | 작성 중 |
| ASOS 분석 보고서 | 기상청 ASOS 관측 자료와 발전 실적을 결합한 분석. 두 번째 입력, 게이트, 드리프트 판정 방법을 실제 수치로 비교 | 넣을 예정 |

## 보관 자료다. 고치지 않는다

보고서는 작성 시점의 상태 그대로 둔다. 그래야 당시 판단의 근거가 된다.

- 보고서의 권고와 다르게 정했으면 보고서를 고치지 않고 [`../decisions/`](../decisions/)에 이유를 적는다.
- 보고서의 내용이 틀린 것으로 드러나면 보고서를 고치지 않고 [`../followups.md`](../followups.md)나 결정 기록에 무엇이 어떻게 틀렸는지 적는다.

## 인용할 때

- 수치에는 조건(기간, 분할 방식, 시드 수)을 함께 옮긴다. 조건이 빠지면 뜻이 달라진다.
- 보고서가 "예측 시점에 받을 수 없는 값을 쓴 수치"라고 표시한 것은 인용할 때도 그 표시를 유지한다.
- 보고서의 수치는 조사 단계의 값이다. 우리 서버로 직접 실행해 얻은 결과와 섞어 적지 않는다.
