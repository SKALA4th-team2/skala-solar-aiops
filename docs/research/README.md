# 조사 자료

프로젝트를 시작하기 전에 한 사전 조사와 데이터 분석의 결과를 둔다. 기획서와 결정 기록이 근거로 가리키는 곳이다.

**조사는 중간에 멈췄다.** 어디까지 됐고 무엇이 남았는지는 [`handoff.md`](handoff.md)에 있다. 처음 읽는 사람은 그 문서부터 본다.

`asos-report.md` 와 `prestudy/` 의 문서에 나오는 "(작업 폴더)"는 조사할 때 쓴 폴더다. 저장소에는 없다. 그 가운데 최종 데이터 파일과 데이터를 만든 스크립트만 [`../../datasets/`](../../datasets/)와 [`../../tools/`](../../tools/)에 옮겨 두었다.

## 보관 자료다. 고치지 않는다

`asos-report.md` 와 `prestudy/` 는 작성 시점의 상태 그대로 둔다. 그래야 당시 판단의 근거가 된다.

- 보고서의 권고와 다르게 정했으면 보고서를 고치지 않고 [`../decisions/`](../decisions/)에 이유를 적는다.
- 내용이 틀린 것으로 드러나면 보고서를 고치지 않고 [`../followups.md`](../followups.md)나 결정 기록에 무엇이 어떻게 틀렸는지 적는다.

`merged/` 는 예외다. 아직 검증이 끝나지 않은 작업 중인 문서이므로, 반박 검증에서 고친 것은 그 문서에 직접 반영하고 무엇을 고쳤는지 끝에 적는다.

## 인용할 때

- 수치에는 조건(기간, 분할 방식, 시드 수)을 함께 옮긴다. 조건이 빠지면 뜻이 달라진다.
- "예측 시점에 받을 수 없는 값을 쓴 수치"라고 표시된 것은 인용할 때도 그 표시를 유지한다.
- 여기 있는 수치는 조사 단계의 값이다. 우리 서버로 직접 실행해 얻은 결과와 섞어 적지 않는다.
