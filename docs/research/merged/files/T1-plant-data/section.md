## 발전소와 데이터의 정의

설비 용량은 55kW 로 통일한다. 한국남부발전과 전력거래소의 문서 네 건이 55kW 로 일치하고 원자료의 시간값이 50 을 넘은 시간이 45개(최대 52.788)이므로, ASOS 분석이 쓴 50kW 는 출처 없는 가정이었고 원자료와도 맞지 않는다. 시간대 열 h 는 한국 표준시 (h-1)시~h시에 쌓인 발전량(kWh, 추정)이고, 용량을 분모로 쓰는 오차율은 용량에 반비례해 바뀔 뿐 배운 모델과 배우지 않은 모델을 가르지 못하므로 게이트에 쓰지 않는다는 데 두 조사의 결론이 같다.

이 절에서 쓰는 말은 다음과 같다.

- "사전 조사"는 웹 조사와 Open-Meteo 날씨로 한 분석 묶음이고, "ASOS 분석"은 기상청 종관기상관측(ASOS) 일자료와 발전 실적을 결합해 실습 LSTM(직전 20일 값으로 다음 날 값을 맞히는 순환 신경망)을 직접 돌린 분석 묶음이다. 두 묶음은 서로의 결과를 모르고 진행됐다.
- "원자료"는 공공데이터포털의 「한국남부발전(주)_하동하수처리장 태양광발전실적_20260228」 CSV 다. 하루가 한 행이고, 요약 열 6개와 시간대 열 1~24 가 있다. "호기"는 발전기 번호다.
- "이용률"은 발전량을 (설비 용량 x 시간)으로 나눈 값이다. "MAE"는 예측과 실제의 차이를 절댓값으로 평균한 값, "RMSE"는 차이를 제곱해 평균한 뒤 제곱근을 취한 값이다. 단위는 둘 다 하루 발전량 kWh 다.
- "예측제도"는 전력거래소의 재생에너지 발전량 예측제도다. 오차율을 시간대별로 |예측 - 실제| ÷ 설비 용량으로 계산하고, 이용률이 10% 이상인 시간대만 평균한다.
- "대리 모형"은 실습 LSTM 대신 가볍게 돌린 회귀 모형(Ridge, 입력은 직전 20일의 일 합계)이다. 대리 모형의 수치는 우리 모델의 성능이 아니다.
- 근거 칸의 `T1/` 은 `(작업 폴더)/merged/T1-plant-data/` 를, `solar/` 와 `asos/` 는 같은 scratchpad 아래의 사전 조사 폴더와 ASOS 분석 폴더를 뜻한다.

### 팀이 정할 것

**1. 설비 용량을 어느 값으로 통일할 것인가**

- 선택지: 55kW 로 통일한다. 50kW 를 그대로 둔다.
- 추천: 55kW 로 통일한다.
- 근거: 문서 네 건이 0.055MW 로 일치한다. 원자료의 시간값은 50 을 45번 넘었고 최대가 52.788 이라 50kW 로는 용량의 105.6% 가 된다. 이웃 4곳은 시간 최대가 공식 용량의 81.2~96.9% 이고 용량을 넘은 곳이 없다.
- 발표까지: 할 수 있다. ASOS 분석의 "용량 대비 MAE" 수치는 다시 학습하지 않고 50/55 를 곱하면 된다(예: 5.51% 는 5.01%). 보고서의 "설비 용량 50kW 는 추정값"이라는 문장 두 곳을 고친다. 50kW 가정에서 나온 후보 입력 "5kW 이상 낸 시간 수"는 발전량만 넣은 모델과 차이가 없던 후보라(RMSE 80.61 / 79.82kWh 대 80.42 / 79.84kWh, 선형 회귀 / 그래디언트 부스팅) 다시 돌릴 필요가 없다.

**2. 용량을 분모로 쓰는 오차율을 기획서와 게이트에 쓸 것인가**

- 선택지: 쓰지 않고 kWh 기준 RMSE 와 합계 대비 절대오차율(절대오차의 합 ÷ 실제값의 합)을 쓴다. 일 단위 오차율(MAE ÷ (55kW x 24시간))을 설명 지표로 쓴다. 예측제도식 오차율을 쓴다.
- 추천: 게이트와 임계값에는 쓰지 않는다. 발표에서 예측제도를 언급할 때만 "시간대별 예측이 있어야 계산할 수 있고, 일 단위 예측을 평균 시간 비중으로 나누면 55kW 기준 11~14% 수준(대리 모형과 단순 예측)"이라고 참고로 적는다.
- 근거: 평가 구간이 조금씩 다르기는 하지만, 55kW 기준 일 단위 오차율은 고정값 예측 5.01%, 20일 평균 5.01%, 대리 모형 4.53%, ASOS 분석의 LSTM 4.73% 로 0.5%p 안에 몰려 있어 배운 모델과 배우지 않은 모델을 가르지 못한다. 같은 예측이 예측제도식으로는 11.45% 라서 6%, 8% 기준과 견줄 수도 없다. 합계 대비 절대오차율은 용량과 무관하다(같은 구간의 고정값 예측 34.8%).
- 발표까지: 할 수 있다. 새 계산이 필요 없다. 우리 LSTM 의 예측제도식 오차율은 시간대별 예측이 없어 발표까지 낼 수 없다.

**3. 화면과 API 명세에 단위와 시간 구간을 어떻게 적을 것인가**

- 발표까지: 할 수 있다. 문구만 바꾸면 된다. 현재 모델은 일 합계만 쓰므로 시간 구간 정의가 예측값에 영향을 주지 않는다.

- 문서 근거는 원문을 다시 내려받지 않았다. 설비 용량, 준공 시기, 좌표, 갱신 주기, 이용 허락 표기, 세화리 열 이름, 오픈API 표기는 작업 폴더에 받아 둔 사본에서 해당 줄을 직접 읽었다. 광양 관측소 좌표, 지번, 용어 정보, 공공데이터법 조문, 과거 판의 행 수, 실적 파일 40개라는 수는 사전 조사의 검증 결과를 그대로 옮겼다.
- 우리 LSTM 의 예측제도식 오차율은 계산하지 못했다. 시간대별 예측이 없다. ASOS 분석 LSTM 의 55kW 기준 수치는 다시 학습하지 않고 환산한 값이다.
- 이웃 4곳은 행 수, 기간, 합계 일치, 0 인 날만 점검했다. 사실상 정지 구간과 복사·수기 입력 여부는 점검하지 않았다.
