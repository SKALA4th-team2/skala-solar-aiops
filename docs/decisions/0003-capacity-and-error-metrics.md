# 0003: 설비 용량과 오차 지표

- 상태: 제안
- 날짜: 2026-10-07
- 정한 사람: (아직 없다. 팀이 확정할 때 적는다)

## 배경

HAIC 스켈레톤은 오차를 RMSE 하나로 재고 단위는 달러다. 태양광에서는 지표를 무엇으로 할지, 설비 용량으로 나눈 비율을 쓸지를 정해야 한다. 재생에너지 발전량 예측제도가 "설비 용량 대비 오차율 4%, 6%"를 기준으로 쓰기 때문에, 우리 수치를 그 기준과 나란히 놓고 싶어지기 쉽다.

용량도 정해야 한다. 조사 초기에는 50kW 와 55kW 가 섞여 쓰였다.

발전량이 0 인 날과 설비가 멈춘 날을 오차 계산에서 어떻게 다룰지도 여기서 정한다. 감시와 재학습에서 다루는 방법은 [0007](0007-facility-vs-model-branch-and-alerts.md)에 있다.

## 검토한 선택지

용량

| 선택지 | 얻는 것 | 잃는 것 |
| --- | --- | --- |
| (가) 55kW | 공식 사양과 같다 | 직류·교류 가운데 어느 쪽 용량인지는 확인되지 않았다 |
| (나) 50kW | 조사 초기의 가정과 이어진다 | 출처가 없다. 시간대 값이 50 을 넘는 칸이 45개 있다 |

지표

| 선택지 | 얻는 것 | 잃는 것 |
| --- | --- | --- |
| (가) RMSE(하루 kWh)를 주 지표로 하고 합계 오차율(%)과 치우침(%)을 함께 적는다 | 실습 코드의 지표와 같다. 치우침으로 "계속 높게 또는 낮게 예측하는가"를 따로 본다 | 계절에 따라 값의 크기가 달라져 절댓값만으로는 좋고 나쁨을 말하기 어렵다 |
| (나) 용량 대비 오차율(평균 절대오차 ÷ (용량 × 24시간)) | 제도의 숫자와 모양이 비슷하다 | 밤 시간이 분모에 들어가 아무 예측이나 5% 안팎이 된다. 제도의 식과 다른 값이다 |
| (다) 제도의 식(시간대별, 이용률 10% 이상인 시간대만) | 제도와 같은 눈금이다 | 우리 모델은 하루 합계 한 값만 낸다. 시간대별 예측이 없어 계산할 수 없다 |

발전량이 0 인 날과 정지일(오차 계산)

| 선택지 | 얻는 것 | 잃는 것 |
| --- | --- | --- |
| (가) 행을 지우지 않고, 전체 오차를 기본으로 적고 정지 후보를 뺀 오차를 보조로 적는다 | 창이 이어진 날짜로 만들어진다. 실제로 일어난 일을 그대로 평가한다 | 정지일이 오차를 키워 모델 비교가 흐려질 수 있다 |
| (나) 정지일 행을 지운다 | 오차가 작아진다 | 실습 코드는 행이 이어져 있다고 보고 창을 만든다. 지우면 창 안의 날짜가 건너뛴다. 정지 목록은 사후에 만든 후보이지 정비 기록이 아니다 |

## 결정

다음을 제안한다.

- **용량은 55kW** 로 적는다.
- **주 지표는 RMSE(하루 kWh)** 다. 함께 **합계 오차율**(절대오차의 합 ÷ 실제 발전량의 합, %)과 **치우침**((예측 합 − 실제 합) ÷ 실제 합, %. 양수이면 높게 예측)을 적는다.
- 지표에는 평가 기간과 일수를 붙인다. 같은 기간의 기준 예측(7일 평균, 규칙C)을 함께 적는다.
- **용량 대비 오차율은 쓰지 않는다.** 참고로 적을 때는 55kW 로 계산하고, 제도의 4%·6% 와 나란히 놓지 않는다.
- **제도의 4%, 6% 는 배경 설명에만 쓴다.** 게이트나 드리프트 임계값으로 옮기지 않는다.
- **발전량이 0 인 날과 정지일은 (가)** 로 다룬다. 원본 행을 그대로 두고 전체 오차를 기본으로 적는다.
- 요청 스키마는 발전량 0 을 받아야 한다([0002](0002-inputs-and-prediction-time.md)).

RMSE 만 보면 치우침이 가려진다. 직접 학습한 모델은 규칙C 보다 RMSE 가 낮지만(41.59 대 45.26kWh) 치우침은 더 크다(−6.0% 대 −0.1%). 그래서 두 지표를 함께 적는다.
