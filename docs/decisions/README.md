# 결정 기록

팀이 정한 것과 그 근거를 한 건씩 남긴다. 기획서 ③ 운영 설계의 숫자는 여기를 근거로 가리킨다.

발표에서 "왜 그 값인가"라는 질문을 받았을 때 답이 있는 곳이다. 정한 값만 적지 않고, 검토한 선택지와 근거 수치, 그 수치의 조건을 함께 적는다.

## 사용 방법

1. [`template.md`](template.md)를 복사해 `NNNN-short-title.md` 로 만든다. 번호는 `0001` 부터 순서대로 쓴다.
2. 근거 수치에는 출처와 조건(기간, 분할 방식, 시드 수)을 붙인다. 예측 시점에 받을 수 없는 값을 쓴 수치는 그렇게 표시한다.
3. 결정이 코드의 숫자를 바꾸면 "함께 고칠 곳"에 [`../../AGENTS.md`](../../AGENTS.md)의 표에서 해당 묶음을 옮겨 적고, 같은 변경에서 맞춘다.
4. 결정을 바꿀 때는 기존 기록을 지우지 않는다. 새 기록을 쓰고 기존 기록의 상태를 "대체됨"으로 바꿔 새 기록을 가리킨다.

## 정해야 하는 것

조사 보고서가 [`../research/`](../research/)에 들어오면 그 권고를 출발점으로 삼아 정한다. 정한 항목은 아래에서 지우고 기록 목록으로 옮긴다.

- [ ] 예측 시점: 대상일 전날 저녁인지 오전인지
- [ ] 두 번째 입력으로 쓸 값
- [ ] 설비 용량으로 쓸 값
- [ ] 배포 게이트의 지표와 기준값
- [ ] 드리프트 판정 방법, 창 길이, 임계값
- [ ] 발전량 0 인 날과 정지일을 학습과 판정에서 어떻게 다룰지
- [ ] 재학습에 쓸 데이터 범위와, 무엇을 재학습의 성공으로 볼지
- [ ] 시연에 쓸 데이터 파일과 구간
