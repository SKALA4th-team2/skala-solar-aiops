# 0006: 감시 지표, 창, 임계값

- 상태: 제안
- 날짜: 2026-10-07
- 정한 사람: (아직 없다. 팀이 확정할 때 적는다)

## 배경

HAIC 스켈레톤은 최근 21건의 예측과 실제의 RMSE 가 4.00 을 넘으면 드리프트로 본다(`serving_app/monitoring/drift_detector.py` 의 `RMSE_THRESHOLD = 4.00`, `WINDOW_SIZE = 21`). 드리프트이면 바로 재학습을 건다.

태양광에서 이 방식에는 두 가지 문제가 있다.

- 4.00 은 달러 눈금이다. 직접 학습한 모델의 21건 RMSE 는 변화가 없는 배치에서도 45.1kWh 였다. 값을 그대로 두면 배치를 보낼 때마다 드리프트로 판정된다.
- 눈금을 kWh 로 고쳐도 RMSE 는 출력 수준의 하락을 잡지 못한다. 직접 학습한 모델에서 발전량을 14% 낮춘 배치의 RMSE 는 34.5kWh 로 오히려 내려갔다. 날씨에 따른 하루하루의 흔들림이 수준 변화보다 훨씬 크기 때문이다.

그래서 무엇을 지켜볼지, 얼마나 모아서 판단할지, 어디서 선을 그을지를 다시 정해야 한다.

이 기록에 나오는 **성능 지표**는 "실제 발전량 ÷ 그날의 관측 날씨로 계산한 기대 발전량"이다. 날씨가 좋았는지 나빴는지를 걷어 내고 설비가 낸 수준만 본다. 대상일의 관측 날씨가 있어야 계산되므로 **예측 시점에는 받을 수 없고, 그날이 지난 뒤의 감시에만 쓴다.**

## 결정

다음을 제안한다.

**주 판정은 성능 지표의 하락이다.**

- **판정은 하루에 한 번 한다.** 관측 날씨가 공개된 뒤 가장 최근 41일(입력 20일 + 판정 21일)을 배치로 보낸다. 지금의 코드는 사람이 배치를 보낼 때만 판정한다. 날마다 자동으로 돌리는 것은 구현 과제다.
- 배치의 뒤 21일에서, 유효한 날의 실제 발전량 합(하루씩 기대 발전량의 0.5 ~ 1.5배로 자른 값)을 기대 발전량의 합으로 나눠 성능 지표를 구한다.
- 기준선은 모델을 올린 날까지의 365일로 같은 식으로 구해 고정한다. 새 모델을 올릴 때와, 사람이 수준이 바뀐 것을 확인했을 때 다시 계산한다.
- 편차(성능 지표 ÷ 기준선 − 1)가 **−7.5% 아래**이면 "출력 수준 저하"로 본다.
- 유효한 날이 **15일에 못 미치면 판정하지 않는다.** 유효한 날의 정의(정지와 보류를 뺀 날)는 [0007](0007-facility-vs-model-branch-and-alerts.md)에 있다.
- 내려가는 쪽만 본다. 올라가는 쪽(회복)은 이 판정으로 잡지 않는다.
- 이 판정은 **알림**의 조건이다. 재학습을 거는 조건은 더 엄격하고 [0008](0008-retraining-and-version-switch.md)에 있다.

**21건 RMSE 는 보조 경고로만 둔다.**

- 게이트를 통과할 때 기록한 시험 RMSE 의 **1.5배**를 넘으면 "입력 이상 의심"이라는 경고를 남긴다. 직접 학습한 모델이면 41.59 × 1.5 = 62.4kWh 다.
- 이 경고는 재학습을 걸지 않는다. 단위가 틀린 값이나 깨진 입력을 알아채는 용도다.

**창 길이 21은 그대로 둔다.** `WINDOW_SIZE = 21` 을 업로드의 최소 행 수(41)와 대시보드가 함께 쓴다.

−7.5% 를 고른 까닭은 오경보와 놓침의 균형이다. −5% 로 내리면 변화가 없는 배치 다섯에 하나가 켜지고, −10% 로 올리면 8.5% 수준의 하락을 절반 가까이 놓친다. 2021년에 실제로 일어난 하락이 앞뒤 1년 기준 8.5% 였으므로 그 크기를 3분의 2 는 잡는 선으로 둔다.

이 기준에는 한계가 있다.

- 임계값, 창, 시작일을 같은 자료에서 보고 골랐다. 다른 해로 검증한 값이 없다.
- 배치가 37개뿐이고 서로 겹친다. 비율을 확률로 읽으면 안 된다.
- 기대 발전량을 계산하는 관측(광양 일사량)이 변하면 가짜 경고가 난다. 가까운 적량면 관측 자료에서는 센서의 수준이 계단처럼 바뀐 일이 세 번 보였다([적량면 관측 자료 검토](../research/jeokryang-sensor.md). 한 사람이 한 분석이고 다른 사람의 재확인을 받지 않았으며 통합 보고서에 들어 있지 않다).
- 성능 지표는 관측 날씨가 공개된 뒤에 계산된다. 그날의 판정은 하루 뒤에야 나온다.
- 위의 임계값 표는 내려간 뒤의 날로 21일이 모두 찬 배치를 센 것이다(내려간 날로부터 41일 뒤). 알림까지의 시간은 날마다 판정한 쪽의 수로 읽는다.
- 2026년 1 ~ 2월은 광양 관측을 받지 못해 성능 지표가 없다.

## 다시 볼 조건

- 2026년 이후의 관측 자료를 받아 다른 해로 오경보 비율을 셀 수 있을 때
- 올라가는 쪽(정비 뒤의 회복)도 자동으로 잡아야 할 때. 계절 곡선 기준선을 검토한다
- 관측 날씨를 날마다 받을 수 없다고 확인될 때. 관측이 필요 없는 판정 방법을 다시 본다
- 배치가 아니라 날마다 감시하는 구조로 바꿀 때. 조사의 "30일 창, −7.5%, 3일 연속" 규칙을 검토한다
