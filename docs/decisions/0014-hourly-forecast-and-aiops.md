# 0014 — 시간별 LSTM과 AIOps 전환

2026-10-07 사용자 요청으로 채택. 시간대별 예측을 범위 밖으로 두었던 이전 결정과 일별 입력 계약은 이 결정으로 대체한다. 전력거래소 제출·정산 검증은 여전히 범위 밖이다.

## 데이터와 시각

기존 승인 33개소 모두 원자료의 1~24시 발전량과 시간별 예보를 확보했다. 하루 합계를 24등분하지 않는다. 원자료의 1열은 당일 00:00~01:00 발전량으로 해석하며, timestamp는 KST(+09:00) 구간 시작이다. 24시간 합계와 원자료 일합계를 대조하고, 음수·비유한값·시간당 설비용량 초과·상충 중복·기상 결측이 있는 날짜 전체를 제외한다. 알려지지 않은 시간을 0으로 채우지 않는다.

기상은 기존 Open-Meteo JMA 지역격자 보관 자료의 previous_day2(48시간 선행) 일사량 W/m², 기온 °C, 운량 %, 풍속 km/h다. 일사량은 직전 한 시간 평균이므로 원래 유효시각에서 1시간을 빼 발전 구간에 맞춘다. 기온·운량·풍속은 같은 유효시각의 예보 특성이다. 지역격자는 발전소 현장 관측소가 아니다. 기존 ASOS 일별 관측을 시간별로 부풀리지 않는다.

[Previous Runs 공식 설명](https://open-meteo.com/en/docs/previous-runs-api)에 따른 고정 선행시간 자료다. 대상일 24시간을 예측하는 자정 시점보다 모든 사용 예보가 앞서도록 day2를 선택했다. 한 번에 발표된 단일 예보 회차라는 의미는 아니며, 당시 실제 공개·수신 시각의 증빙은 없어 publication_cutoff_verified=false다.

## 모델·평가·승인

발전소별 LSTM: 전날 실적 24시간과 대상일 예보 24시간 → 대상일 1시간 발전량 24개. 특징 9개는 전날 같은 시간 발전량/설비용량, 일사량/1000, 기온/40, 운량/100, 풍속/30, 시간·연중일 sin/cos다. 훈련 기간에 맞춘 일사량 선형 기준선에 LSTM 24유닛의 잔차를 더한다. 고정 물리 정규화·기준선 계수를 scaler.pkl에 저장하고 재학습에서 바꾸지 않는다. 출력은 0~설비용량×1시간, 예보 일사량 ≤1 W/m² 구간은 0이다.

학습 <2024-07-01, 검증 2024-07~12, 독립 평가 2025년. 검증 조기 종료로 epoch를 선택하고 2024년까지 다시 학습한 평가 모델로 2025년을 한 번 평가했다. seed=42. 아래 게이트는 전체 개소 실행 전에 코드에 고정했으며 결과를 보고 완화하지 않았다.

- 최소 180개의 유효 평가일.
- 시간별 전체 RMSE ≤ 전날 같은 시간 유지 기준선 RMSE의 95%.
- RMSE ≤ 훈련 일사량 기준선 RMSE의 105%.
- 발전량 합계 편향 절댓값 ≤15%.
- 주간(예보 일사량 ≥20 W/m²) RMSE ≤ 일사량 기준선 주간 RMSE의 105%.

31개 통과, 신인천전망대(15043395-u1)·용수리(15095404-u1) 2개는 시간별 품질 미달로 운영 목록에서 제외한다. 시간자료 부재로 제외된 개소는 0개다. 하동 평가 RMSE 4.4506 kWh/시간. 최신 배포 모델은 선택 epoch로 전체 가용 자료를 재학습했다. 화면의 현재 모델 과거 재생 오차와 독립 평가 오차를 구분한다. 이번 시간별 릴리스는 LSTM이며 예전 XGBoost·Prophet·앙상블 일별 비교 결과를 시간별 성능으로 사용하지 않는다.

## 시간별 AIOps

최근 7일 168시간에서 일사량 ≥20 W/m²인 구간이 48개 이상이어야 판정한다. 실적 합/훈련 일사량 기준선 합 <0.85이면서 RMSE가 최초 배포 한도를 초과하면 재학습 후보로 본다. 예보 일사량 ≥150 W/m²인데 실적이 기준선의 10% 이하인 구간이 3시간 연속이면 데이터·설비 점검 보류로 분기한다. 이는 예보 오차의 영향을 받는 잔차 검사이며 관측기상 보정 PI나 설비 고장 확정 판정이 아니다.

재학습은 연속 29일(696시간): 첫날은 lag24, 다음 21일 학습, 마지막 7일 검증. 대상 시간이 기존 모델 학습 종료 이후여야 한다. 기존 scaler와 모델을 불러와 5epoch 추가 학습한다. 검증 RMSE ≤ 최초 한도와 동일 창 기존 모델 RMSE를 모두 만족해야 MLflow 등록·승격한다. 실패하면 기존 버전 유지. 검증 7일은 후보 가중치 학습에 넣지 않는다.

SQLite 내구 작업 큐, 단일 작업자, OS 잠금, 같은 개소·종료시각 작업 중복 방지 및 데이터 해시 충돌 차단, 비정상 종료 복구(최대 2회), hash 검증 모델 교체, 명시적 버전 롤백을 사용한다. 업로드 또는 배치 검사 시 모니터링과 조건부 큐 등록을 수행한다. 실시간 외부 API 자동 수집은 이 릴리스에 포함하지 않는다.
