# 0009: 시연의 구성, 자료, 구간

- 상태: 제안
- 날짜: 2026-10-07
- 정한 사람: (아직 없다. 팀이 확정할 때 적는다)

## 배경

기획서 ⑥ 은 모델 버전 전환 전후의 응답, 컨테이너 실행 화면, 드리프트 주입에서 알림과 재학습으로 이어지는 로그를 실제 화면으로 보여야 한다.

HAIC 스켈레톤의 시연은 `scripts/simulate_drift.py` 가 만든다. 학습 자료의 평균값에서 시작하는 무작위 가격 41개를 두 벌 만들어, 한 벌은 평소의 변동으로, 한 벌은 변동을 3배로 키워 보낸다. 둘째 값은 서버가 1,200,000 이라는 고정값으로 채운다(`routers/predict.py` 의 `SIMULATED_VOLUME`).

태양광에서는 이 방식을 그대로 쓸 수 없다.

- 둘째 값을 고정하면 예보를 넣어 학습한 모델이 뜻 없는 값을 낸다. 직접 학습한 모델로 재 보니 21건의 예측이 모두 276.4kWh 로 같았고 RMSE 가 111.1kWh 였다.
- 변동을 키운 무작위 값은 태양광에서 일어나는 일이 아니다. 실제로 일어난 일은 출력 수준의 하락이다.
- 실제 하락(2021년 5월)이 있던 때에는 예보 자료가 없다. 예보는 2022-07 부터 있다.

그래서 무엇을 실제 사건으로 보이고 무엇을 인위로 만들어 보일지, 어느 날짜를 쓸지를 정해야 한다.

## 결정

(가)를 제안한다. 장면마다 쓰는 자료와 날짜는 다음과 같다.

함께 정하는 것은 다음과 같다.

- **모델을 둘로 나눈다.** 품질 비교에는 업로드 파일 전체로 학습한 모델을 쓴다. 재학습 장면에는 학습 정답일이 2025-02-28 에서 끝나는 모델을 따로 학습해 쓴다. 뒤의 자료로 통과한 게이트를 앞 시점의 배포 근거로 쓰지 않기 위해서다. 두 모델의 학습 끝 날짜, 스케일러, 버전을 화면에 구분해 적는다.
- **주입은 0.86 을 쓴다.** 사본은 `tools/` 의 스크립트로 만든다. `datasets/` 의 원본은 손대지 않는다.
- **시연용 사본은 2025-07-31 에서 끝낸다.** 서버가 "가장 최근에 올린 파일의 마지막 41행"으로 재학습하기 때문이다([0008](0008-retraining-and-version-switch.md)). 2025-08-01 ~ 08-21 은 재학습 뒤의 평가에 남긴다.
- **조사의 수치를 화면의 결과 자리에 넣지 않는다.** 조사에서 이 장면의 재학습 전후 RMSE 가 38.9kWh 에서 31.1kWh 였다는 값은 참고로만 적는다.
- **게이트에서 막히는 것도 유효한 장면이다.** "기존 운영 버전 유지"를 보이는 장면으로 쓴다. 통과를 보이려고 실행한 뒤에 기준을 바꾸지 않는다.
- **버전이 실제로 바뀐 것을 확인할 수 없으면 "새 모델로 서빙한다"고 말하지 않는다.** 승격 로그만으로는 부족하다([0008](0008-retraining-and-version-switch.md)).
- **화면이 준비되지 않으면** `scripts/simulate_drift.py` 의 터미널 출력과 `aiops.log` 로 대신한다. 대시보드의 배치 단추는 브라우저에서 무작위 가격을 만들어 보내므로, 실제 행을 보내도록 고치기 전에는 태양광 시연에 쓰지 않는다.

## 다시 볼 조건
