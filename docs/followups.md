# 나중에 확인할 것

지금은 판단할 근거가 없거나 다른 것이 먼저 끝나야 해서 미뤄 둔 것을 모은다. 미뤘다는 사실을 적어 두지 않으면 조건이 갖춰진 뒤에도 아무도 다시 오지 않는다.

팀이 선택지 가운데 하나를 골라야 하는 것은 여기가 아니라 [`decisions/`](decisions/)의 "정해야 하는 것"에 둔다.

## 규칙

- 항목을 끝냈으면 지우지 않고 "완료"로 표시하고, 무엇을 확인했고 결론이 무엇이었는지를 적는다. 그냥 지우면 확인한 것인지 잊은 것인지 구분되지 않는다.
- "언제" 칸에는 무엇이 갖춰지면 볼 수 있는지를 적는다.
- 발표까지 확인하지 못한 것은 기획서에서 어떻게 다룰지(가정으로 명시, 범위 밖으로 선언)를 함께 적는다.
