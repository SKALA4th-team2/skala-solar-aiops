# T6·T7 반박 검증 (2026-10-07)

## 재현

저장소 루트에서 `python tools/verify/t6t7_independent.py .`를 실행한다. 의존성은 numpy, pandas다. 원본 CSV와 통합 일자료만 읽으며 프로젝트 모듈을 import하지 않는다. 결과는 표준출력으로 내므로 필요하면 별도 파일에 저장한다.

공식 문서 대조는 `t6t7_source_evidence.json`에 출처 URL, 새 다운로드 SHA-256, 파일 크기, 확인 조항·조건을 남겼다. 파일 자체를 저장소에 넣지 않았다. 새로 받은 공식 PDF 두 개와 HWP를 준비하면 `t6t7_source_evidence.py --rule RULE.pdf --broker BROKER.hwp --market MARKET.pdf`로 확인할 수 있다(pypdf, olefile 필요). 시장 통계의 표는 PDF67쪽을 이미지로 렌더링하여 직접 읽었다.

## 중요한 수정

1. **1%p → 약9%는 실제 사업자의 효과를 추정한 확률분포가 아니다.** 같은 평균5.71%라도 정산단가와 +1%p 효과는 다를 수 있다. 동일 발전량을 갖는 두 시간대에 오차율이 각각5.71%이면 +1%p로 단가3원→0원, 오차가0%·11.42%이면 평균은 같지만 단가2원→2원이다. 이 구성 반례는 관측 결과가 아니며 시험한7~17%가 실제 상하한이 될 수 없음을 보인다. 기존 업계 전망의약5%도 다른 분포·기준선이라는 이유만으로 반증되지 않는다.
2. **상쇄3.7~10%는 표본·예측 방식의 조건부 값이다.** 작은 공간표본의 날씨 상관, 날씨 예보 없는 PERS·MA7, 사후 중심창 정지 판정, ORA의 대상일 실제 합계 사용을 구분한다. 실제 사업자 예보모델의 공간상쇄를 이 숫자로 확정하지 않는다. 이웃 캐시가 없어 이번 집합 수치는 독립 재현하지 못했다.
3. **추종과 탐지는 실제 운영조건의 검증이 아니다.** 13일·20일 추종은 T-1날씨 열이 들어간 합성실험의 씨앗1개 결과다. 실제 제출 시점에는 그 날씨가 미공개다. 2~4주 알림은 전체 기간을 보고 기준을 고른 표본 안 결과다. 재학습 효과 없음이라는 일반명제보다 기존 시험에서 큰 개선이 입증되지 않았다고 쓴다. 현재 프로젝트 코드는 RMSE감지→자동 재학습 스켈레톤으로 설비 점검 알림 분기가 구현되어 있지 않다.
4. **T6 RMSE와 WAPE를 혼동한 괄호를 고쳤다.** 17시 잠정 합계의 독립 재현은 RMSE2.178kWh, WAPE0.747%다. 월별 계수는2023-05-31이전 자료로만 구하고 평가946일을 썼다. 17시 보정 입력으로 한 예측 모델 검증과 실시간 계량 입수는 별도 미확인이다.
5. **가입 조건의 예외가 빠져 있었다.** 중개시장 제33조의2는 등록 후 추가를 원칙적으로 제한하지만 제35조의2는 용량 복원, 소형자원 비중 복구, 준중앙급전 참여 목적의 추가를 허용한다. 처음부터 하동을 포함하는 것은 검증 가능한 시나리오 가정이지 유일한 법적 경로가 아니다. 20MW초과 조건 때문에 하동 비중은0.275%미만이며0.275%는20MW의경계값이다.
6. **공식 지급 실적을 새로 찾았다.** 전력거래소 『2025년도 전력시장 통계』(2026.5) PDF67쪽/인쇄133쪽4-1-2·3에2025년 정산 대상 발전량6,203,420MWh, 정산금23,484,457천원(약234.84억원)이 있다. 월별금액의 합을 검산했고 표 이미지를 확인했다. 일반 작성기준에서2023~2025금액은잠정치다. 2025전체수치이며2026육지태양광·중개사업자별 실적이 아니므로171MW가상사업자시산과대체하지 않는다. 같은쪽사업자표는2024년이다.
7. **2021년변화 지속기간을 확정하지 않는다.** 05-14와05-18의두 유효 이웃대비관측은 사이의 변화를 보여주지만 ASOS의14일·30일변화 배제불가 단서를 지울 수 없다. 직접재계산한 통합PI의직후1년 기준대비수준은-8.4714%, 반사실발전량차이6595.74kWh다. 계기수준변화등으로인과손실확정은못한다.
